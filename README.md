# TXT Leech Bot

Converts ClassX / AppX course TXT files into Telegram videos.

## Deploy on Render

1. Push to your GitHub
2. Render → New → Web Service → connect repo
3. Set env vars: API_ID, API_HASH, BOT_TOKEN, PORT=8080
4. Deploy

## Usage

Send /upload → follow the prompts → bot downloads and sends each video.

See full README in the repo for details.
